🚀 dimil designer.dev | Portfólio Profissional
Este portfólio foi desenvolvido para documentar minha jornada de transição de carreira, unindo 25 anos de experiência no mercado criativo com as tecnologias mais modernas do desenvolvimento web. O objetivo é demonstrar como o rigor técnico do desenvolvimento Front-end encontra o olhar clínico do design.

💡 Sobre o Projeto
Este projeto foi construído como uma Single Page Application (SPA) de alta performance, focada em acessibilidade, SEO otimizado e uma experiência visual refinada. Mais do que um site, é a materialização da minha visão técnica: código limpo, interfaces fluidas e foco total no usuário (UX).

🛠 Tecnologias e Stack
Desenvolvido com o que há de mais atual no ecossistema web:

Framework: Next.js 15+ (App Router)

Estilização: Tailwind CSS v4 (Estilização utilitária e performática)

Animações: Framer Motion (Micro-interações e UX Delight)

Linguagem: React.js e JavaScript (ES6+)


🌟 Principais Funcionalidades
Modo Dark Nativo: Sistema de cores responsivo com transições suaves.

Filtragem Dinâmica: Sistema de busca por categorias (Front-end, Back-end, UI, Motion, etc.) integrado ao portfólio.

Performance de Elite: Otimização de imagens e Core Web Vitals para carregamento instantâneo.

Identidade Visual Híbrida: Integração de texturas (Mesh Gradients) com tipografia de alta legibilidade.

Sou um profissional de transição de alto impacto: Capaz de resolver problemas complexos através da união entre estética e lógica.
